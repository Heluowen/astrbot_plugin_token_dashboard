# astrbot_plugin_token_dashboard · Token 用量看板

给 [AstrBot](https://github.com/AstrBotDevs/AstrBot) 用的 token 消耗可视化插件：把模型调用量、**前缀缓存命中率**、按会话拆分、单次请求明细和**分时段成本估算**都做成一个页面看。

数据全部来自 AstrBot 自带的 `provider_stats` 表，**只读**，不改任何东西，也不往 LLM 请求里注入内容——所以不会影响对话质量，也不会拖累缓存命中率。

## 功能

- 📊 **总览卡片**：请求数、输入 token（命中 / 未命中）、缓存命中率、输出 token、估算花费
- 📈 **时间序列**：每时段输入 token 堆叠柱状图（绿=命中缓存，红=未命中）+ 命中率折线
- 🗂 **按会话拆分**：每个群 / 私聊的请求数、输入量、命中率、花费
- 🧾 **最近请求**：逐条列出命中 / 未命中、输出、计费时段、花费
- 🕘 **分时段计费**：按北京时间区分高峰 / 空闲两档单价，逐条请求在其发生时刻的档位计价
- 💬 **聊天命令**：`/token [小时数]` 直接在聊天里看用量
- ⏱ 页面自动刷新（间隔可配）

## 安装

把本仓库放进 AstrBot 的插件目录，然后重启 AstrBot：

```bash
cd <AstrBot 数据目录>/plugins
git clone https://github.com/<your-name>/astrbot_plugin_token_dashboard.git
```

也可以在 AstrBot WebUI 的插件页用「从 URL 安装」。

## 使用

**看板**：打开 AstrBot WebUI → 插件页 → 「Token 用量看板」

**命令**：

```
/token        # 近 24 小时
/token 168    # 近 7 天
```

## 配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `db_path` | 空（自动探测） | AstrBot 数据库路径，一般不用填 |
| `price_input_miss_peak` | 2.0 | 高峰 · 输入（缓存未命中），元/百万 token |
| `price_input_hit_peak` | 0.04 | 高峰 · 输入（缓存命中） |
| `price_output_peak` | 8.0 | 高峰 · 输出 |
| `price_input_miss_offpeak` | 1.0 | 空闲 · 输入（缓存未命中） |
| `price_input_hit_offpeak` | 0.02 | 空闲 · 输入（缓存命中） |
| `price_output_offpeak` | 4.0 | 空闲 · 输出 |
| `peak_windows` | `09:00-12:00,14:00-18:00` | 高峰时段窗口（北京时间） |
| `holidays` | 空 | 法定节假日日期，JSON 数组 |
| `session_labels` | 空 | 会话 ID → 名称的映射（JSON） |
| `refresh_seconds` | 60 | 看板自动刷新间隔，0 为不刷新 |

上表单价是 DeepSeek 的参考价，请按自己实际账单核对后调整。

### 计费时段规则

- **高峰**：北京时间，周一至周五（不含法定节假日），`09:00-12:00` 与 `14:00-18:00`
- **空闲**：其余全部时间，包括周末、法定节假日全天、夜间与午休

节假日每年由国务院公布，插件不内置日历，需要手动填一次：

```json
["2026-01-01", "2026-02-16..2026-02-22", "2026-10-01..2026-10-07"]
```

支持单日与 `开始..结束` 区间写法。留空时节假日当天的工作时段会按高峰价计。

### 会话名称

```json
{"2132379270": "潮汕牛肉火锅", "336611682": "私聊-老友"}
```

## 说明

- 花费是按 token 数与配置单价**估算**的，不含任何平台优惠或阶梯价
- 缓存命中率只反映服务商侧的前缀缓存是否命中，与插件无关
- 数据来源表 `provider_stats` 由 AstrBot 自己维护，本插件只做聚合展示
